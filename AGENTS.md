# AGENTS.md — правила работы

Проект: «Смета за 5 минут» (см. README.md).

## Порядок работы

- Работать только в этой папке.
- Сначала прочитать текущие файлы, потом менять.
- Делать только ту функцию, которую просит пользователь.
- Не ломать уже работающие функции.

## Технологии

- Только обычные HTML, CSS и JavaScript.
- Без npm, фреймворков, сборщиков и внешних ресурсов (CDN, шрифты, картинки по ссылке).

## Данные и приватность

- Данные пользователя остаются в браузере.
- Ничего не отправлять в интернет.

## Удобство

- Понятные подписи у всех полей и кнопок.
- Поля и кнопки — не меньше 44 px по высоте и ширине нажатия.
- Всё работает с клавиатуры (Tab, Enter, видимый фокус).
- Всё удобно на телефоне.

## Деньги и числа

- Деньги показывать с пробелами между тысячами: `15 000 ₸`.
- Пустые и неверные числа считать нулём.
- Никогда не показывать `NaN`.

## Git и публикация

- Не запускать git и ничего не публиковать без просьбы пользователя.

## После работы

- Перечислить изменённые файлы.
- Описать, как проверить результат.
